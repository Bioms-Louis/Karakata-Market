# Karakata Market
# 🛒 Karakata – Fullstack E-commerce Platform

Karakata is a modern fullstack e-commerce web application built with React, Node.js, and PostgreSQL (Supabase). It provides a seamless shopping experience with product browsing, cart management, authentication, and admin controls.


## 🚀 Features

### 👤 User Features
- User registration & authentication (JWT-based)
- Browse products by category
- Add to cart & manage cart items
- Wishlist functionality
- Secure checkout process

### 🏪 Vendor Features
- Vendor registration & authentication
- Create and manage product listings
- Upload and update product images
- Track and manage inventory
- View sales and product performance
- Control product availability (in stock/out of stock)
- Manage orders related to their products

### 🛠️ Admin Features
- Add, update, and delete products
- Upload product images
- Manage carousel/banner content
- Control product visibility

### ⚙️ System Features
- RESTful API architecture
- Cloud image hosting (ImgBB)
- Persistent database (PostgreSQL / Supabase-ready)
- React Query for efficient state management


## 🏗️ Tech Stack
### Frontend

### Backend
